# Task 3 – Advanced CSS & JavaScript Project

## Project Overview

This project demonstrates the implementation of Responsive Web Design, Interactive JavaScript Functionality, and API Integration using HTML, CSS, and JavaScript.

The application consists of:

* A responsive webpage that adapts to different screen sizes.
* An interactive quiz section.
* A Random Joke Generator that fetches real-time data from a public API.

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API

---

## Features

### 1. Responsive Design Using Media Queries

The webpage automatically adjusts its layout and styling based on the device screen size.

#### Mobile View

* Screen width: 600px and below
* Reduced font size
* Container width adjusted to 95%
* Background color changes

#### Tablet View

* Screen width: 601px to 992px
* Medium font size
* Tablet-friendly layout

#### Desktop View

* Screen width: 993px and above
* Standard desktop layout

---

### 2. Interactive Quiz

The quiz section displays a question with two options.

Question:
"HTML stands for?"

Options:

1. Hyper Text Markup Language
2. Home Tool Markup Language

Functionality:

* Displays "Correct Answer" when the correct option is selected.
* Displays "Wrong Answer" when the incorrect option is selected.

---

### 3. API Integration

The project uses the Fetch API to retrieve a random joke from a public API.

API Used:
https://official-joke-api.appspot.com/random_joke

Functionality:

* User clicks the "Get Joke" button.
* JavaScript sends a request to the API.
* The received joke is displayed dynamically on the webpage.
